# Code of conduct

NAS Project Cloud should be a friendly place to ask questions, report problems, and contribute, whatever your experience level.

## What we expect

- Be respectful, and assume the other person means well.
- Keep feedback about the work, not the person.
- Help newcomers along: point them at the docs, the [good first issues](https://github.com/JonathanBeck1/nas-project-cloud/labels/good%20first%20issue), or explain why something is done a certain way.

## What isn't acceptable

- Harassment, insults, or personal attacks.
- Discriminatory language or jokes.
- Publishing someone else's private information.
- Deliberately derailing discussions.

## Where this applies

Issues, pull requests, discussions, and any other space that belongs to the project.

## Reporting and enforcement

Report a problem privately to the maintainer by email, using the address on [@JonathanBeck1's GitHub profile](https://github.com/JonathanBeck1). Reports are kept confidential. Depending on what happened, the maintainer may edit or remove content, give a warning, or block someone from the project temporarily or for good.

The spirit of this document follows the [Contributor Covenant](https://www.contributor-covenant.org/).
